# 阶段 1：图书策划（Book Planning）

本阶段目标：在动笔前与作者对齐「写什么、给谁看、解决什么问题、做到什么程度」，产出可指导后续大纲与写作的《图书策划方案》。

## 1.1 启动项目时的必问项

新项目启动时，**单轮内**采集以下信息，提问 ≤ 3 个/轮，缺失信息才问，已给信息不再追问。

### A. 作者信息
1. 您的身份与专业背景？（决定权威口径与案例来源）
2. 写作经验如何？（新手/有过发表/资深作者，影响引导粒度）
3. 希望通过这本书达成什么目标？（个人品牌 / 知识沉淀 / 商业变现 / 教学 / 影响行业）

### B. 图书信息
4. 想写什么主题？希望为读者解决什么具体问题？
5. 面向哪类读者？（专业同行 / 入门者 / 大众 / 学生，决定深度与术语策略）
6. 预计书籍规模？（篇幅区间，如 8–10 万字 / 15–20 章，影响大纲粒度）
7. 是否计划出版？载体倾向？（纸质书 / 电子书 / 自费 / 机构内刊 / 仅自用）
8. 有无参考作品或理想样板？（书名或类型，用于定位对标）

### C. 事实验证模式（关键，必须询问）
启动项目时明确询问：

> 「本书是否需要开启事实验证模式？可选：关闭 / 基础 / 专业 / 严格。
> - 关闭：小说、创意、观点表达类，按您的创作方向自由书写，AI 不主动核查。
> - 基础：检查明显事实/时间/逻辑硬伤。
> - 专业：科普/技术/商业，附来源建议与数据核查提醒。
> - 严格：医学/法律/金融/学术，附引用建议与来源追踪、风险提醒。」

作者选择写入 `00_BOOK_PROJECT.md` 的 `fact_check_mode` 字段，后续全程生效。若选「关闭」，严格尊重，绝不主动强制验证。

## 1.2 输出：《图书策划方案》

按 `references/08-output-templates.md` 的模板生成，至少包含：

- **书名建议**：给 3–5 个候选（含副标题），说明各自定位与卖点，供作者挑选，不替作者定名。
- **副标题**：强化核心价值或读者承诺。
- **图书定位**：一句话说清「这是什么书、处在哪个细分市场」。
- **目标读者**：画像 + 真实痛点 + 阅读场景。
- **核心价值**：读者读完能得到的具体收获（能力/认知/方法）。
- **内容方向**：主题疆界，明确写什么、不写什么。
- **差异化优势**：相较参考作品/同类书的独特切口或方法论。

## 1.3 交互约束

- 不替作者拍板书名与定位，提供选项 + 推荐理由，由作者定。
- 若作者信息过少，先用合理假设补全方案并标注「假设项」，请作者确认或推翻。
- 策划方案确认后，才进入阶段 2。未确认不跳阶。
