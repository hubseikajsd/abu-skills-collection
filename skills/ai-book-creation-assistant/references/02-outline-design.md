# 阶段 2：大纲设计（Outline Design）

本阶段目标：将《图书策划方案》展开为可逐章执行的《完整图书大纲》。遵循渐进式原则——先全书骨架，再章，再节。

## 2.1 大纲层级

```
全书结构（1 份）
 ├─ 核心主题
 ├─ 核心观点（书的「中心论点」或「价值主张」）
 ├─ 内容逻辑（整体叙事/论证主线，如问题→方法→实践→升华）
 └─ 章节结构（编号 + 章名 + 一句话定位）

每章设计（每章 1 份）
 ├─ 本章目标（读者读完本章获得的认知/能力）
 ├─ 核心问题（本章要回答的关键问题）
 ├─ 内容框架（小节顺序与逻辑）
 ├─ 案例 / 方法 / 关键观点（预埋要点）
 └─ 与前后章的衔接

每节设计（每节 1 份）
 ├─ 内容目的
 ├─ 信息重点（2–4 个 MUST 传达的信息）
 ├─ 论述逻辑（如何展开：定义→对比→案例→结论）
 └─ 示例建议（类型即可，如「用一个行业反例」）
```

## 2.2 生成顺序

1. 先输出「全书结构」草案，请作者确认主线逻辑与章节数量。
2. 作者确认后，逐章输出「每章设计」，可分批评量但每章独立确认。
3. 章节确认后，对当前要写的章输出「每节设计」（不必一次性铺满全书，配合阶段 3 渐进展开）。

## 2.3 大纲质量自检

- 章节之间是否存在清晰进阶或并列关系，无重大重叠。
- 是否覆盖策划方案承诺的「核心价值」与「内容方向」。
- 开头是否建立动机，结尾是否收束并指向行动/认知升级。
- 专业书：逻辑是否可独立成「方法论闭环」；科普书：是否有贯穿全书的叙事钩子。

## 2.4 输出：《完整图书大纲》

按 `references/08-output-templates.md` 模板生成。大纲确认后写入 `02_OUTLINE.md`，并将章节清单同步进 `00_BOOK_PROJECT.md` 的进度表（状态置「未完成」）。
