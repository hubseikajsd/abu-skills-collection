# 阶段 4：文风控制系统（Style System）

本阶段目标：在启动时与作者锁定全书的文风，并在写作中保持统一。提供 12 种文风，分 4 大类；按主题、读者、目标推荐，但最终由作者决定。

## 4.1 文风矩阵

### 专业型（面向同行/学员，重严谨与体系）
| 文风 | 特征 | 典型适用 |
|---|---|---|
| 学术论文风 | 定义精确、论证严密、引用规范、克制主观 | 学术专著、研究综述 |
| 教材风 | 由浅入深、结构清晰、配习题/小结、术语可控 | 高校/职业培训教材 |
| 行业专家风 | 权威口吻、实战视角、框架+案例、少废话 | 行业研究、专业实务书 |

### 大众型（面向广泛读者，重可读与共鸣）
| 文风 | 特征 | 典型适用 |
|---|---|---|
| 商业畅销书风 | 金句密集、痛点开场、节奏明快、强行动导向 | 商业管理、个人成长 |
| 故事化风格 | 用叙事承载观点、场景描写、人物弧光 | 经验分享、思想类 |
| 科普传播风 | 通俗比喻、生活化举例、去术语化、好奇驱动 | 科学传播、人文科普 |

### 作者型（突出个人声音，重真实与思辨）
| 文风 | 特征 | 典型适用 |
|---|---|---|
| 第一人称经验分享 | 我story、亲历案例、坦诚得失 |  memoir、方法论 |
| 思考型 | 设问推进、辩证、留白、慢节奏 | 思想类、随笔 |
| 演讲型 | 呼告式、互动感、金句与排比、感染力强 | 观点书、号召类 |

### 实用型（面向行动者，重清晰与可用）
| 文风 | 特征 | 典型适用 |
|---|---|---|
| 操作指南 | 步骤化、清单化、可直接照做 | 指南、手册 |
| 方法论 | 抽象框架+落地路径、模型图表化 | 方法论、工具书 |
| 工具书 | 条目化、检索友好、定义+用法 | 词典式、参考手册 |

## 4.2 推荐规则（仅建议，作者终审）

- 主题 × 读者 × 目标 三者交叉决定基调：
  - 专业书 + 学员 → 教材风 / 行业专家风
  - 科普 + 大众 → 科普传播风 / 故事化风格
  - 商业管理 + 大众 → 商业畅销书风
  - 个人成长 + 亲历 → 第一人称经验分享
  - 技术/操作类 → 操作指南 / 方法论
- 一书可设「主风格 + 局部变体」（如主风格行业专家风，案例段用故事化），变体须作者确认并在 `00_BOOK_PROJECT.md` 记录。
- 风格切换属于方向性改动，必须征得作者同意，并更新状态文件。

## 4.3 风格锁定与一致性

- 启动时给出「推荐风格 + 理由 + 备选」，作者选定后写入 `00_BOOK_PROJECT.md` 的 `style` 字段。
- 写作中若检测到偏离锁定风格（如科普书突然堆术语、畅销书风突然变学术腔），以一致性备忘提示作者，不擅自改写。
