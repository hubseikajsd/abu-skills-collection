# 输出格式规范（Output Templates）

所有阶段性文档统一遵循以下模板，确保可续写、可检索、可出版。生成任意文档前先对照本文件。

## 8.1 图书策划方案（01_PLANNING.md）

```markdown
# 《图书策划方案》—— <暂定主题>
生成日期：YYYY-MM-DD

## 书名建议（请作者选定，AI 不代定）
1. 《候选书名A》—— 副标题：…（定位：…，卖点：…）
2. 《候选书名B》—— 副标题：…（定位：…，卖点：…）
3. 《候选书名C》—— 副标题：…（定位：…，卖点：…）

## 图书定位
一句话：这是一本面向<读者>的<类型>书，解决<问题>。

## 目标读者
- 画像：…
- 痛点：…
- 阅读场景：…

## 核心价值
读者读完将获得：<具体能力/认知/方法>。

## 内容方向
- 写：…
- 不写：…

## 差异化优势
相较<参考作品/同类书>：独特切口是…。

## 事实验证模式
<off | basic | professional | strict> —— <选择理由>
```

## 8.2 完整图书大纲（02_OUTLINE.md）

```markdown
# 《完整图书大纲》—— <书名>
## 全书结构
- 核心主题：…
- 核心观点：…
- 内容逻辑：<主线，如 问题→方法→实践→升华>
- 章节结构：
  - 第1章 <章名>：<一句话定位>
  - 第2章 <章名>：…

## 第 N 章设计
- 本章目标：…
- 核心问题：…
- 内容框架：<小节顺序>
- 案例/方法/关键观点：…
- 前后衔接：…

### 第 N 章 · 第 M 节设计
- 内容目的：…
- 信息重点：…
- 论述逻辑：…
- 示例建议：…
```

## 8.3 章节正文（chapters/NN_slug.md）

```markdown
# 第 N 章 <章名>
> 本章目标：…（回扣大纲）

## 第1节 <节名>
（正文。遵循锁定文风；预埋增强块用「> 增强：…」标注以便作者删改）

## 第2节 <节名>
（正文）
```

## 8.5 一致性备忘（每次生成后内联提示）

```markdown
> 一致性备忘（AI 辅助，供作者裁定）
> - 术语：本段「X」与 TERMS 中「Y」是否同一概念？建议统一为「Y」。
> - 事实[专业模式]：第3段数据建议核查来源类型：官方统计。
> - 风格：本节偏故事化，与主风格「行业专家风」略有出入，是否保留为变体？
```

## 8.6 出版素材（publishing 阶段）

```markdown
# 出版准备
- 目录（提取自 02_OUTLINE.md）
- 序言草稿：…
- 作者简介：…
- 书封文案（主标题+副标题+一句话卖点+三段简介）：…
- 出版建议：<载体/节奏/合规提醒，依 fact_check_mode>
```

## 8.7 排版约定

- 默认简体中文；Markdown。
- 标题层级：H1 书名 / H2 章 / H3 节 / H4 段。
- 对外可选项用编号清单，便于作者挑选。
- 假设项一律标注「[假设]」，待作者确认。
