## v1.0.0 — 初始构建（2026-07-09）

**来源**：need-to-skill-flow 解码 → 构建。基于 credible-writer v1.1.0 改造。

**核心决策**：
- 复用 credible-writer 的「去AI味」(24+6模式+2026维度) 与「去幻觉」(来源分级/事实判断分离/正反辩驳/评分) 引擎
- 去幻觉领域化：证据从"网页来源"改为"记忆来源分级"（🥇日记原文/🥈口述佐证/🥉记忆重建/❓存疑）
- 新增回忆录工艺层：素材接入、声线选择、场景vs概述、show-don't-tell、诚实审查(不虚美不隐恶)
- 新增回忆录专属 AI tell（套路煽情/伪乡愁/通用怀旧/金句腔/全知心理戏/腔调同质化）
- 借鉴 BiographyLibrary（分章结构+引导提问+出版前筛查）、MemoirAI（口语/日记→章节）

**健康度**：text_health_scanner = 100/100（7 文件，959 行，0 high/medium/low）

**验证证据**：examples.md 含 3 个完整范例（日记→回忆录、口述整理、诚实补正），覆盖去AI味+记忆溯源+声音保留。

**FP 命中**：无（初始构建，幼年阶段，只建已验证结构）

**下一步候选改进（VFM 待评）**：
- 加"年表自动提取"辅助脚本（从日记批量抽年代/事件）→ 观察
- 加 PDF 导出模板（献词/尾声，借鉴 BiographyLibrary）→ 观察
- 多语言（方言 preservation 规则细化）→ 观察

## v1.1.0 — 补全导出打印版闭环（2026-07-09）

**动机**：用户要把回忆录打印给长辈（老丈人，~90 岁）过目，需"写→打印→反馈→改"闭环。
原 skill 只产出 Markdown，缺打印交付环节。

**改动**：
- 新增 `scripts/make_print.py`：Markdown → 长辈友好 DOCX（正文 15pt / 行距 1.75 / 首行缩进两字 / 章节分页 / 页脚页码 / 自动标题页），保留 🥇🥈🥉❓ 与 `[文学重建]` 标记，表格渲染为带表头底纹的网格表。
- SKILL.md 新增「导出打印版（长辈反馈闭环）」一节：脚本用法 + 反馈闭环流程（长辈圈改→发回→Layer2 针对性修订→再导出，末尾追加修订记录）。
- 版本升 1.1.0。

**实跑验证**：朱兵《我的平生履历》原版（8万字）→ 样章 Markdown → 打印版 DOCX（104 段、2 表、14 处证据标记齐全，校验通过）。

**注意**：text_health_scanner 仅适用 skill 目录（要求 SKILL.md 存在），对单篇成稿不适用；成稿质量以稿内「去AI味 6 条自检」+ 诚实审查替代。

**下一步候选改进（VFM 待评）**：
- 长辈反馈结构化：打印版圈改 → 用户提供意见 → 自动 diff 并定位到 Layer2 修订点（待用户反馈后评）
- PDF 导出模板（献词/尾声，借鉴 BiographyLibrary）→ 观察
- 年表自动提取脚本 → 观察

## v1.2.0 — 据 SkillHub 审核反馈整改（2026-07-10）
