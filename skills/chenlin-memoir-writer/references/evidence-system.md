# 记忆来源分级系统（Memoir Evidence System）

> 去幻觉·领域化核心——回忆录的"证据"不是网页来源，而是**记忆来源**。
> 改编自 credible-writer 的证据系统，专为日记/口述素材设计。

---

## 一、记忆来源等级

| 等级 | 含义 | 来源类型 | 示例 |
|------|------|----------|------|
| 🥇 日记/文献原文 | 最可靠 | 日记、书信、档案、户口本、老照片背面字迹 | "日记 1987-03-12：'今日调往xx厂'" |
| 🥈 口述佐证 / 实物 | 较可靠 | 传主后来口述、家人确认、照片/实物印证 | 子女证"爸确实那年在砖窑"、照片显示地点 |
| 🥉 记忆重建 | 需谨慎 | 从模糊记忆重建，合理但未经核实 | "大概七几年，具体年头记不清了" |
| ❓ 存疑 | 无法确认 | 道听途说、完全想不起来、与他人说法冲突 | "听说当年是因为…"（无佐证） |

### 判断规则
1. **优先用 🥇**——有日记原文，不用口述替代
2. **核心事件至少 🥈**——影响章节走向的事件不能用 ❓
3. **🥉 只用于辅助背景**——提供氛围，不支撑关键论断
4. **找不到就标 ❓**——不编造、不猜测、不"合理脑补成事实"

---

## 二、事实 vs 文学重建 分离（回忆录特有）

回忆录允许文学化，但必须让读者分清"真"与"演"。

### 事实（有素材支撑）
```
**事实**：1987 年 3 月，老丈人从乡下调往县城砖窑厂做工。
- 来源：🥇 日记 1987-03-12
- 记忆可信度：95%
```

### 文学重建（日记无此记录，为场景感补充）
```
**文学重建**：那天清晨，他背着铺盖站在村口，母亲在身后没说话，只把两个熟鸡蛋塞进他兜里。
- 标明：日记只记"调往xx厂"，母子送别场景为合理推测，非日记原文
- 标注格式：正文用 [文学重建：…] 或叙述中明确"据说/想来是"
```

### 分离原则
- 事实 = 可溯源的客观陈述
- 文学重建 = 感官/对话/心理补充，**日记中并无此记录**
- **永远不要把文学重建包装成事实**
- 读者有权知道：这段是真的，那段是我合理想象的

---

## 三、诚实审查（不虚美不隐恶）

每章成稿后强制过一遍：

- [ ] 是否只写了好、没写不好？→ 补上真实的缺点、失误、犹豫
- [ ] 是否把传主写成完人？→ 加一处瑕疵或矛盾（他也会抱怨、也会错）
- [ ] 作者有没有跳出来直判"他真是个好人"？→ 删，用事实让读者感受
- [ ] 对看不惯的人/事，是否带了恩怨？→ 回到事实，不发泄

---

## 四、记忆可信度计算

类比 credible-writer 置信度，但维度改为"记忆来源质量"：

```
记忆可信度 = (来源等级完整度) × 0.4
           + (🥇🥈 来源占比) × 0.2
           + (独立 corroboration 数) × 0.2
           + (诚实审查未发现虚美? 0.1 : 0)
           - (来源缺失惩罚) × 0.1
```

### 来源等级完整度
| 状态 | 完整度 | 示例 |
|------|--------|------|
| 完整 | 100% | 核心事件有 🥇 日记 + 🥈 口述印证 |
| 较完整 | 70% | 只有 🥇 或只有 🥈 |
| 部分 | 40% | 只有 🥉 记忆重建 |
| 不完整 | 0% | 仅 ❓ 存疑 |

### 强制规则
- 核心事件来源完整度 < 50%（仅 ❓/🥉 且无印证）→ **标"记忆模糊"**，不写成确凿事实
- 完整度 50–70% → 警告，建议补充素材
- 完整度 > 70% → 可正常成稿

## 五、不同亚文体的溯源要求

| 亚文体 | 来源分级 | 文学重建标注 | 诚实审查 | 记忆可信度 |
|--------|---------|------------|---------|-----------|
| 严肃传记体 | 强制🥇🥈🥉❓ | 强制标注 | 强制 | 强制 |
| 温情回忆录 | 标注核心事实 | 建议标注 | 强制 | 建议 |
| 家族史料 | 强制（零误差） | 几乎不用 | 强制 | 强制 |
| 口述整理 | 标🥇🥈即可 | 不添加 | 建议 | 不计算 |

## 六、标注规则（位置 / 时机 / 场景）⚠️ 评估器重点整改项

上文定义了"标什么等级"，本节明确"**标在哪里、何时必标、哪些场景必须标**"。规则不遵守，等于没溯源。

### 6.1 标注位置（两种写法，二选一，全稿统一）

**A. 行内标记**（首选，最不破坏阅读）：把等级符号直接跟在事实后，用半角空格隔开。
```
1987 年 3 月调到县城砖窑厂，月工资四十二块 🥇
母亲在门口站了很久 🥈
```
- 适用：正文叙事中、单句即一个事实。读者边读边见来源，不打断。

**B. 段末括号**（次选）：事实较多或需说明来源细节时用。
```
那年因家庭困难申请转业（🥈 妻儿随军又离散，家人转述；日记仅记"申请转业"）
```
- 适用：一个句子含多个事实、或来源需补充说明（如具体日期、谁转述）。

**C. 写作说明区块**（交付物用）：成稿末尾的"记忆来源标注"清单，逐条列核心事实+等级，供快速核查。
- 这是 A/B 的**汇总**，不是替代——正文里仍要标 A 或 B，否则读者得翻到末尾才知道真假。

> 禁止：只在末尾清单标、正文不标（读者读正文时无法判断）；或只标 emoji 不写任何说明（❓ 必须配一句"为何存疑"）。

### 6.2 何时必标（强制时机）

| 时机 | 动作 | 理由 |
|------|------|------|
| 出现具体人名/地名/年代/日期 | 标 🥇 或 🥈，并尽量附具体出处 | 这类是"保护片段"，错一处即毁信 |
| 引用日记/书信/文献原话 | 标 🥇 + 出处（如"日记 1987-03-12"） | 原话不可改，必须可回溯 |
| 出现照片/实物印证的信息 | 标 🥈 + "照片显示/实物为证" | 实物是硬证据 |
| 出现"大概""记得好像""那年头"等模糊词 | 标 🥉 或 ❓ | 暴露记忆不确定，必须显式 |
| 章节收尾做"记忆来源标注"清单 | 列全部核心事实等级 | 交付前核查 |
| 用户问"这段真的假的" | 能立刻指回 🥇/🥈 出处 | 溯源系统的终极检验 |

### 6.3 哪些场景必须标 `[文学重建]`

只要**日记/口述/实物中均无此记录**，且你补了以下内容之一，就必须标：

- **对话**：传主或他人的具体台词（除非日记原文抄录了对话）
- **心理活动**："他心想…""那一刻他明白了…"
- **感官/场景细节**：天气、光线、气味、动作神态等让场景"活"起来的描写
- **因果联想**："因为穷，所以…"（日记只记事实，未记因果）

标注三种写法（选一，全稿统一）：
1. 行内：`[文学重建：想来那两个鸡蛋是头天特意留的]`
2. 段末：`（[文学重建] 母子送别场景为合理推测，日记只记"调往xx厂"）`
3. 措辞法：用"据说/想来/大约是"等词显式弱化，等同标注

> 边界：纯属于"概述"的衔接句（如"那几年他在厂里慢慢站稳了脚跟"）若不添加具体虚构细节，可不标；一旦加了具体场景/对话/心理，必标。

### 6.4 不标的情况（避免滥标污染）

- 纯逻辑连接词、时间过渡（"后来""第二年"）不标
- 已成公开常识、无需溯源的背景（"抗美援朝 1950 年爆发"）可不标，但涉及传主具体经历仍要标
- 用户明确要求"别标来源、只要干净文字"时：尊重，但**文学重建标注不可省**——这是诚实底线，可用弱化措辞法代替显式 `[文学重建]` 标签

## 七、常见回忆录幻觉及防御

| 幻觉模式 | 表现 | 防御 |
|---------|------|------|
| 编造日期 | "1979 年那个春天…"但日记无此 | 标 ❓ 或查实，否则不写具体年 |
| 编造对话 | 大段心理独白/对话，日记无 | 标 `[文学重建]` |
| 美化传主 | 只写勤奋善良，隐去暴躁失职 | 诚实审查补瑕疵 |
| 通用怀旧 | "物质匮乏但人情温暖"套所有年代 | 回到具体日记细节 |
| 张冠李戴 | 把哥哥的事安到传主身上 | 人名列为保护片段，逐字核对 |
| 年代错位 | 把 80 年代的事写到 70 年代 | 对照日记年份 |
| 因果硬编 | "因为穷所以奋发"但日记只记事实 | 标为"可能相关"，不写死因果 |
