# 回忆录写作范例（日记 → 回忆录）

> 四个完整示例：日记素材成稿、口述整理、诚实补正、长辈反馈闭环。展示"去AI味 + 记忆溯源 + 声音保留 + 写→打印→反馈→改闭环"。

---

## 示例一：日记素材 → 温情回忆录章节

### 用户输入（素材）
> 老丈人日记摘录：
> "1987年3月12日。今日接到通知，从乡下调往县城砖窑厂。工资每月四十二块。母亲没说话，塞给我两个熟鸡蛋。"
> 口述补充（妻子转述）："你爸说那天早上天还黑，他背个铺盖就走了，母亲在门口站了好久。"

### 回忆录成稿
```
## 第三章 去砖窑的那天

1987 年 3 月 12 日，我接到通知，从乡下调到县城砖窑厂，月工资四十二块（🥇 日记）。

天还黑着，我背起铺盖出了门。母亲没说话，往我兜里塞了两个熟鸡蛋（🥇 日记）。她在门口站了很久（🥈 妻子口述）。

[文学重建：想来那两个鸡蛋是头天特意留的，平时舍不得吃。] 四十多年后他讲起这事，还是那句："你奶奶一辈子，话少，事实在。"

---

### 写作说明
**亚文体**：温情回忆录
**声线**：传主第一人称（据日记口吻）
**力度**：standard

**记忆来源标注**：
- 1987-03-12 调往砖窑厂、工资 42 块：🥇 日记原文
- 母亲门口站很久：🥈 妻子口述
- 鸡蛋是特意留的：🥉 记忆重建（标为正文"想来…"）

**事实 vs 文学重建**：
- 事实：调厂、工资、塞鸡蛋（🥇）
- 文学重建：鸡蛋特意留、母亲心理（标"想来/据说"，日记无此记录）

**诚实审查**：本章为早年艰辛，未虚美；传主"话少事实在"为真实性格侧面，非直判。

**记忆可信度**：核心事件 95%（🥇+🥈）

**质量评分**：
| 维度 | 得分 |
|------|------|
| 真实感 | 10 |
| 在场感 | 9 |
| 声音 | 9 |
| 诚实度 | 10 |
| 节奏 | 9 |
| 精炼度 | 9 |
| **总分** | **56/60** |
```

### 对比：AI 套路化写法（反面，应避免）
> ❌ "1987 年的那个清晨，寒风凛冽。他背起行囊，迈向命运的转折点。母亲默默站在身后，那一刻，他忽然懂了什么叫离别与担当。这条通往砖窑的小路，承载着一个时代的重量……"

问题：伪乡愁景物（寒风/小路）、套路煽情（命运的转折/时代的重量）、全知心理（忽然懂了）、虚美拔高。无一标来源。这正是 memoir-writer 要消灭的。

## 示例二：口述整理（口语 → 保留声音）

### 用户输入
> 老丈人白话："那时候闹啥嘛，厂里活重，我细胳膊细腿的，师傅还骂我。我说咋办嘛，干就完了。后来嘛，慢慢的也就习惯了，说到底还是得活。"

### 整理后
```
那时候闹啥嘛，厂里活重，我细胳膊细腿的，师傅还骂。我说咋办嘛，干就完了。后来慢慢也就习惯了——说到底，人得活。
```
修改说明：保留"闹啥""咋办嘛""说到底"等口头禅（声线），只删重复"慢慢的也就"、补一个破折号断句。未添加任何文学重建，未改意思。质量评分 口语原味保留，声音 10/10。

## 示例三：诚实补正（去虚美）

### 初稿（虚美）
> "父亲一生勤劳善良，从不与人红脸，是邻里交口称赞的老好人。"

### 诚实审查后
```
父亲勤是勤，脾气也倔。七九年跟邻居老李为半尺墙基吵了半个月，谁也不让（🥈 家人转述）。
他后来自己说："那时候年轻，较真。" 倔归倔，活儿从不含糊。
```
补正：加了真实的吵架瑕疵（不虚美），用传主原话"年轻较真"收，不直判"老好人"。诚实度 4→10。

## 示例四：长辈反馈闭环（打印 → 圈改 → 修订 → 重导）

展示 `memoir-writer` 的完整使用回路：成稿打印给传主过目 → 传主圈改 → 回到 Layer 2 做**针对性修订**（只改被质疑处，不重洗全文）→ 再导出新版并在末尾追加「修订记录」。

### 第一步：导出打印版（交给长辈）
```bash
python scripts/make_print.py \
  --input 回忆录样章.md \
  --output 打印版_v1.docx \
  --title "我的平生履历（回忆录样章）" \
  --author "朱兵 著 · 家人协助整理" \
  --subtitle "温情回忆录 · 征求意见稿（欢迎提修改意见）"
```
长辈拿到大字号打印稿，边读边用红笔圈改。

### 第二步：长辈圈改意见（用户发回）
> 传主在《冰河上的夜》一处批注："停战那晚我不是站岗，是在坑道里睡觉，岗是别人站的，你莫写错了。"
> 另在《放牛娃与剃头匠》批："打虎队那截写得好，莫删。"

### 第三步：Layer 2 针对性修订（只动被质疑处）
```
## 冰河上的夜（修订）

七月二十七日晚，我在坑道里睡着。外头飞机声、枪炮声震耳欲聋，火光从出入口映进来，
是我入朝以来从未经历的。到了二十二时，骤然寂静。我好生奇怪……（🥇 日记；据传主圈改正文：
当夜本人未在岗，岗哨由同排战友轮值）
```
- **只改这一句**，其余照旧；不重洗全章。
- 圈改中"写得好莫删"的部分保持原样，不做多余改动。

### 第四步：再导出版 + 追加修订记录
重新跑 `make_print.py` 生成 `打印版_v2.docx`，并在成稿**末尾追加**：

```
---

### 修订记录

**v1 → v2（据传主圈改）**
- 修正：《冰河上的夜》停战当夜场景——传主本人当夜在坑道休息，非站岗；已按亲述改正，并标 🥇 来源说明。
- 保留：《放牛娃与剃头匠》"打虎队"一节，传主认可，未动。
- 未改动：其余章节。
```
闭环完成。每一轮反馈都只追加一条修订记录，便于长辈核对"哪改了、哪没改"。

> 要点：**反馈闭环的修订是增量、可追溯的**，不是推倒重来。这既尊重传主意愿，也保住已建立的记忆溯源体系。
