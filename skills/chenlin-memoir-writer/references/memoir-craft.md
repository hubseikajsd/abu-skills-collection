# 回忆录工艺手册（Memoir Craft）

> 传记/回忆录的根本规律与成稿技法。本文件是 memoir-writer 的"工艺层"核心。

---

## 一、传记/回忆录六大根本规律

### 1. 真实为骨
> "其文直，其事核，不虚美，不隐恶。" —— 班固《汉书》评司马迁

- 骨架必须是真的：人名、地名、年代、重大事件节点
- 允许文学化（场景、对话重建），但**骨架不能歪**
- 真到什么程度，就写到什么程度；写不到的，标出来

### 2. 细节为肉
- 叙行录言：既写他做了什么，也写他说了什么
- 重视细节：一个动作、一句原话，胜过三段评价
- **Show, don't tell**：用具体动作和感官代替形容词

### 3. 声音为魂
- 保留传主自己的：口头禅、方言词、句式习惯、看世界的视角
- AI 写回忆录最大的破绽：**所有人回忆录都一个腔调**
- 代笔时，声线是"借来的"——要让读者觉得是老人在讲，不是 AI 在演

### 4. 结构为脉
- 按人生阶段分章：早年 / 求学 / 成家 / 事业 / 晚年（可增删）
- 或主题式：苦难、手艺、亲情、时代
- **详略得当**：关键事件用场景，平淡岁月用概述

### 5. 诚实为德
- 优缺点并重、功过并举，不神话人物
- 写传基数忌：忌恩怨用事、忌无据材料、忌轻给活人立传、忌作者直接表态
- 作者不跳出来喊"他是个好人"——用事实让读者自己感受

### 6. 在场感（presence）
- **场景（scene）**：慢镜头，有时间地点感官动作对话，用于高潮/转折
- **概述（summary）**：快进，用于过渡/平淡岁月
- 比例失衡（全概述=流水账；全场景=拖沓）都会失真

## 二、素材→回忆录 工作流

```
1. 采集素材（日记/口述/照片笔记）
2. 记忆溯源分级（🥇🥈🥉❓）
3. 选定亚文体 + 声线
4. 选结构（人生阶段 or 主题）
5. 写场景（关键事件）
6. 去AI味 + 反煽情
7. 诚实审查（补瑕疵）
8. 交付 + 质量评分
```

**没有素材时**：用下方"引导式记忆提问清单"唤醒，绝不凭空写。

---

## 三、场景构建四要素（Show, don't tell）

把一段概述变成场景，问自己四个问题：

| 要素 | 问自己 | 反面（tell） | 正面（show） |
|------|--------|------|------|
| 时间地点 | 那天具体在哪、什么时辰？ | "他年轻时很苦" | "1962 年冬，他在县城砖窑里，手冻得握不住锹" |
| 感官 | 看到了/闻到了/听到了什么？ | "环境很差" | "窑里全是红土味，咳出来的痰都是红的" |
| 动作 | 他具体做了什么？ | "他很勤劳" | "天不亮他就去挑水，一担八十斤，往返六趟" |
| 对话 | 当时说了什么原话？ | （无） | "师傅骂他：'你这细胳膊能干啥？'他没吭声，把扁担往肩上一扛" |

> ⚠️ 对话/心理若日记无记录，必须标 `[文学重建]`，见 evidence-system.md。

## 四、声音提取与保留

动笔前，先从素材里扒出传主的"声音指纹"：

1. **口头禅**：他爱说的词（"说到底""闹啥""妥了"）
2. **句式**：短促还是绵长？爱用反问还是陈述？
3. **视角**：他是乐观派、耿直派、还是爱抱怨？
4. **方言**：哪些词用方言更有味（保留，首次可括注）

成稿时：用他的词、他的节奏、他的视角去讲。**去 AI 味在回忆录里 = 把声音还给他。**

## 五、引导式记忆提问清单（无素材时唤醒用）

按人生阶段给传主/家人提问，收集 🥇/🥈 素材：

**早年（0–18）**
- 你出生那天，家里是什么情形？谁在场？
- 最清楚的童年一个画面是什么？（气味/声音/人）
- 上学走多远？路上有什么？
- 小时候最怕/最盼的一件事？

**成家立业（18–40）**
- 怎么认识另一半的？第一次见面说了什么？
- 第一份工多少钱？最难的一天怎么过的？
- 分家/搬家那年，发生了什么？

**中年（40–60）**
- 最骄傲的一件事？最丢脸的一件？
- 家里最难的那几年，怎么熬过来的？
- 有没有和谁吵过一架，至今记得？

**晚年（60+）**
- 退休第一天干啥了？
- 最想留给子孙的一句话/一样东西？
- 这辈子最后悔什么？最不后悔什么？

> 每个答案记下来时，标注是从日记来的（🥇）、口述的（🥈）、还是后来回忆的（🥉）。

## 六、结构模板

### 人生阶段式（最通用）
```
扉页 / 献词（给子孙）
第一章 早年（出生–求学）
第二章 闯世界（成家–立业）
第三章 最难的那几年（转折/苦难）
第四章 安稳日子（中年–晚年）
尾声（留给子孙的话）
```

### 主题式（适合素材零散）
```
第一章 一双鞋（物质记忆）
第二章 一张全家福（亲情）
第三章 一声吆喝（时代声音）
第四章 一碗面（乡愁）
```

### 家族史料式（编年）
```
[年份] [事件] [出处]
1958 生于xx村（🥇日记）
1976 娶亲（🥈口述）
1983 迁居xx（🥇日记）
```
