# 回忆录质量评分系统

> 6 维度 60 分制（回忆录定制）+ 交付前自查清单 + 36 项 AI 味检查（复用 credible-writer）。

---

## 六维度评分（回忆录定制）

### 1. 真实感（/10）—— 溯源可靠度
**评估**：每个核心事实能否指回素材？来源分级是否到位？
- 10：核心事实全有 🥇/🥈，文学重建全标注
- 7：大部分有来源，个别未标
- 4：多处无来源或靠 ❓ 撑
- 1：大量编造未标

### 2. 在场感（/10）—— 场景构建力
**评估**：关键事件是否落成场景（感官/动作/对话）？概述与场景比例？
- 10：高潮有画面、有感官、有动作，平淡处快进
- 7：有场景但偏概述
- 4：通篇概述=流水账，或通篇场景=拖沓
- 1：无画面感

### 3. 声音（/10）—— 传主声线
**评估**：读起来像传主本人，还是像通用 AI 回忆录？
- 10：有口头禅、有视角、有节奏差异，三人回忆录三种味
- 7：基本自然，声线略淡
- 4：干净但无灵魂，谁写都一个样
- 1：机械腔

### 4. 诚实度（/10）—— 不虚美不隐恶
**评估**：优缺点并重？作者没跳出来直判？
- 10：有瑕疵有矛盾，用事实说话
- 7：基本诚实，个别美化
- 4：明显虚美，完人传记
- 1：恩怨宣泄/严重失真

### 5. 节奏（/10）—— 句子变化
**评估**：句子长短是否变化？打破 AI 节奏一致性？
- 10：长短交错自然，有碎片句有长句
- 7：有变化但不明显
- 4：多数同长
- 1：机械重复

### 6. 精炼度（/10）—— 无冗余
**评估**：还有可删的吗？
- 10：无冗余，每句有信息
- 7：少量可删
- 4：填充短语多
- 1：废话连篇

### 评分标准
| 总分 | 等级 | 说明 |
|------|------|------|
| 54-60 | 优秀 | 真实+在场+声音+诚实+节奏+精炼六达标 |
| 45-53 | 良好 | 有改进空间，查最低维 |
| 36-44 | 及格 | 需修订，重点最低维 |
| <36 | 不及格 | 需重写 |

## 交付前自查清单

### 去AI味 / 反煽情
- [ ] 有"忽然明白了人生意义"式强行升华？删
- [ ] 无来源的景物抒情（夕阳/石板路/老屋）？删（除非有素材）
- [ ] 所有年代都写成"匮乏但温暖"？打破通用怀旧
- [ ] 连续三句同长？打断一个
- [ ] 有"此外""值得注意的是"？删
- [ ] 破折号/三段式/金句腔？修正
- [ ] 全知心理戏未标文学重建？标或删

### 去幻觉 / 记忆溯源
- [ ] 每个核心事实标了来源等级（🥇🥈🥉❓）？
- [ ] 日记无记录的对话/心理/场景标了 `[文学重建]`？
- [ ] 有无编造的日期/事件？删或标 ❓
- [ ] 事实与文学重建分离标注？
- [ ] 有人问"真的假的"能指回日记/口述？

### 回忆录工艺
- [ ] 关键事件落成场景（感官/动作/对话）？
- [ ] 声音像传主，不像通用 AI？
- [ ] 只写优点没写缺点（虚美）？补瑕疵
- [ ] 作者跳出来直判"他是个好人"？删，用事实
- [ ] 结构详略得当（高潮场景/平淡概述）？
