# 回忆录亚文体风格包

> 四类回忆录亚文体，各有语域、结构、溯源要求。写作时据 Layer 1 选择加载。

---

## 一、严肃传记体（Serious Biography）

### 语域
- 客观、克制、第三人称为主（"他"/"陈老"）
- 不抒情、不煽情、不跳出来表态
- 用词准确，年代/地名零误差

### 结构模板
```
[标题：某某某传 / 个人史]

引子：[一句定调，不抒情]
一、早年（出生–求学）
二、闯世界（成家–立业）
三、转折（关键事件）
四、晚年
尾声：[留给时代的注脚，克制]

附录：年表、资料来源
```

### 去AI味要点
- 删空洞意义拔高、删伪乡愁景物抒情
- 保留客观陈述与 🥇 日记原话引用
- 力度：minimal（传记不宜大改）
- scope：in-place

### 溯源要求
- 强制来源分级 + 文学重建标注 + 记忆可信度

---

## 二、温情回忆录（Warm Memoir）

### 语域
- 有叙事感、有情感、可读性强
- 第一人称（传主"我"或子女代笔"父亲/我爸"）
- 允许口语、允许适度抒情，但**抒情须有具体事实托底**
- 不写鸡汤式金句

### 结构模板
```
[标题：给子孙的话 / 某某的人生故事]

[引子：一个具体画面或一句话]
[主体：按人生阶段或主题，场景与概述交错]
[收尾：留给子孙的话，克制真诚]
```

### 去AI味要点
- 注人声音——用传主的词、节奏、视角
- 变化节奏——短句。然后长句慢慢展开。
- 允许一点乱——跑题、题外话是人味
- 抒情必须有"下雨那天他没带伞"这种具体事，不空抒情
- 力度：aggressive（可重写，但保声音）
- scope：structural

### 溯源要求
- 核心事实标注来源；文学重建建议标注
- 诚实审查强制（不虚美）

---

## 三、家族史料（Family Chronicle）

### 语域
- 编年、事实优先、零修饰
- 人名、地名、年代必须准确
- 不抒情、不评价

### 结构模板
```
[年份] [事件] [出处]
1958 生于xx村（🥇日记）
1976 娶亲（🥈口述）
1983 迁居xx（🥇日记）
...
```

### 去AI味要点
- 几乎不用修辞，纯事实罗列
- 力度：minimal
- scope：in-place

### 溯源要求
- 强制零误差，每条标 🥇/🥈
- 不用文学重建（史料不演）

---

## 四、口述整理（Oral Transcription）

### 语域
- 保留口语味道：口头禅、重复、停顿感
- 只去冗余、去跑题过远，不改写意思
- 第一人称"我"原样

### 结构模板
```
[按口述时序或主题分段]

[整理后的口语文字，基本保留原话]
```

### 去AI味要点
- **这是反向去AI**：不是把口语改"规范"，是把规范拉回"人话"
- 保留"闹啥""说到底""妥了"等口头禅
- 删：重复三遍的同一件事、过远的题外话
- 力度：minimal（几乎不改写）
- scope：bounded（只删冗余，不重排意思）

### 溯源要求
- 标 🥇（录音/口述）/ 🥈（其他印证）即可
- 不添加文学重建

---

## 亚文体切换矩阵

| 从\到 | 严肃传记 | 温情回忆录 | 家族史料 | 口述整理 |
|-------|---------|-----------|---------|---------|
| 严肃传记 | - | 增第一人称、增情感 | 增编年、删抒情 | 增口语、降客观 |
| 温情回忆录 | 降情感、增客观、删抒情 | - | 增年份、降场景 | 增口语、降文学 |
| 家族史料 | 增叙事、降编年 | 增场景、降零修饰 | - | 增口语 |
| 口述整理 | 增客观、删口语冗余 | 增文学、降原话 | 增年份标注 | - |
